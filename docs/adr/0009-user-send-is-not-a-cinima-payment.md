# User Send is not a Cinima payment

Cinima cannot charge for catalog data (TMDB). Incoming `tipTxHash` on Thanks was retired for that reason. Cycle 2 still needs a user-approved Pay sheet, so one-to-one Thanks may attach a User Send: 1 NIM from the thanker's wallet to the thankee, never to Cinima. The Pay memo is a custom note from a fixed list (Send Custom Message). Rewards from the Sender wallet stay. Thank all does not open Pay sheets.
