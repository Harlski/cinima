# Watchlist Share is its own public page, not Public Profile

Watchlist is a save-for-later queue, not a taste mark. Putting it on Public Profile would mix "what I love" with "what I haven't watched." A Watchlist Share is a separate ask: here is my list, help me pick what is next. The page is live with the current Watchlist (not a snapshot) so the question stays current. Sharing is opt-in from My List; empty Watchlists cannot be shared.
