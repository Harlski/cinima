# Joined the crew is awarded on Join grant, before the Guided tour

ADR 0005 withholds Achievements until the Guided tour is skipped or completed so Credits do not show a prize for tour actions before the walkthrough is done. Joined the crew is a welcome for signing in, not a lesson from the tour. It is the one Achievement inserted on Join grant even when the tour is still unresolved. It does not count as already having an Achievement for the tour gate. Other kinds stay behind the gate.
